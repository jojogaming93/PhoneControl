`phonecontrol-logo.png` is original artwork generated with the built-in image generation tool. It contains no device capture or personal data. `phonecontrol.ico` packages the approved artwork at 16, 24, 32, 48, 64, 128 and 256 pixels for Windows. Run `scripts/Build-BrandAssets.ps1` on Windows to rebuild the icon. The public-source audit pins the reviewed PNG and ICO SHA-256 values; changes require visual review and updated pins.
