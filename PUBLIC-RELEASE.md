## Clean repository

`scripts/Prepare-PublicRepository.ps1` creates a separate, source-only checkout
under `artifacts/public/PhoneControl`, with a fresh `main` branch and one initial
commit. It copies audited source files, not the original `.git` directory, local
build output, screenshots, settings, downloaded tools or credentials. It configures
the public origin without contacting it or changing a CLI login.

The public commit uses `jojogaming93` and the synthetic address
`noreply@example.invalid` for both author and committer. That address is a
placeholder, not a personal mailbox. Original private ancestry, tags, reflogs,
commit messages and account settings are never imported.

Run from a private development checkout:

```powershell
python docs/generate_fixtures.py
python docs/build.py
python scripts/Check-PublicSource.py
./scripts/Prepare-PublicRepository.ps1
```

Use the generated checkout for a public push. After authenticating a Git client
to the intended public account, run there:

```powershell
python scripts/Check-PublicSource.py --history
git push -u origin main
```

If the destination already contains commits, inspect them before combining
histories; do not force-push as part of this preparation. A browser upload can
instead use the extracted source-only ZIP beside the checkout. GitHub's upload
page expects files/folders, so extract it before uploading. The ZIP excludes
`.git`, compiled output and local credentials.

## Privacy checks

`Check-PublicSource.py` checks the source allowlist, personal local paths, email
addresses, private keys, archive contents and reproducible generated images.
With `--history`, it also checks every reachable commit/blob and synthetic
author/committer attribution. Optional `PUBLIC_DENY_TERMS` supplies a JSON array
of additional private identifiers locally; findings print only paths/reasons.
Keep that private list out of source and CI logs.

Also scan the fresh checkout and all public history with Gitleaks. Never upload
private scan reports, old installers/source archives, local backups or logs.
Secret scanners detect known patterns; new attachments and release artifacts
still require review.

Private phone/game screenshots are excluded entirely. Public PNG fixtures and
the SVG atlas are generated by `docs/generate_fixtures.py` from anonymous control
coordinates and four small arrow luminance grids. They contain no chat,
inventory, usernames, phone identifiers or image metadata. The fixtures verify
decoding, dimming, resizing/capture and worker behavior; they do not replace new
live-game acceptance. Supported games are listed only in the root README.

Original AI-generated PhoneControl artwork in `assets/branding` is separately
reviewed and pinned by SHA-256 in the source checker. It is not a device capture.
Only those exact branding files are excepted from fixture reproducibility checks.
